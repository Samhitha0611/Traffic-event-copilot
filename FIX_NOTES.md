# Fix pack: why other Hyderabad locations gave wrong plans

## How to apply
1. Unzip this pack INTO your project root (Traffic-event-copilot). It overwrites the listed files.
   It is based on the app.py you uploaded; if you changed app.py since, merge by hand.
2. `py -m pip install -r requirements.txt`
3. `py -m pytest -q`   (50 tests should pass)
4. `py scripts/prepare_city_data.py --check`   then   `py scripts/prepare_city_data.py --hospitals`
5. `py -m streamlit run app.py`

## What was wrong (all fixed)
| # | Problem | Fix |
|---|---|---|
| 1 | Road download timed out on overpass-api.de, then the code silently used the UPPAL roads for any venue | `src/osm_download.py`: tests 4 servers in 6 s each, reuses covering cached maps, remembers failures, never falls back. The app shows a clear error + Retry |
| 2 | The page kept the old result when you changed venue until you pressed Run | Result is re-run whenever any input changes |
| 3 | Emergency corridor always started at Habsiguda (Uppal) | Nearest hospital from `data/hyderabad_hospitals.csv`; none found = corridor skipped and a warning |
| 4 | Traffic approaches were fixed Uppal names or equal N/S/E/W guesses | `auto_approaches()` reads main roads from each venue's own map; shares follow road capacity |
| 5 | Scenario-preset table was cached from the first venue | Cache now keyed by venue |
| 6 | Manual parking/hospital rows applied to every venue | Only rows within 5 km of the venue are used |
| 7 | `hyderabad_hourly_traffic_profiles.csv` was generated by a script with made-up numbers but labelled "HMDA CTS / Telangana RTA / IRC:106" | Relabelled SYNTHETIC-ASSUMED everywhere. Real published counts added in `data/real_count_anchors.csv` |

## New files
- `src/osm_download.py`, `scripts/prepare_city_data.py`: one-time road map + hospital download for all venues
- `src/observed_speeds.py`, `scripts/collect_tomtom_speeds.py`: collect REAL hourly speeds with a free TomTom key
- `data/real_count_anchors.csv`: real published counts with source links
- `tests/test_wrong_roads_fix.py`: 15 tests proving the fixes

## Not tested here
Live downloads from OpenStreetMap and the TomTom API (my sandbox cannot reach them). The logic is tested with mocks.
Server addresses in `osm_download.py` can change; edit them or set the OVERPASS_URLS environment variable.
